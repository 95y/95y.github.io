Deno 当时想解决的问题

Deno 1.0 发布，默认限制文件、网络和环境变量权限，并内置 TypeScript、格式化、测试等工具。

Deno 没有立即替代 Node.js，但它推动运行时竞争重新活跃，并影响后来的权限模型、原生 TypeScript 支持和工具集成方向。
