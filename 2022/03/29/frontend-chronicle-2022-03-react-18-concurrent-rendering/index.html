React 18：并发渲染、自动批处理与流式 SSR

发表于2022-03-29|更新于2022-03-29|前端年鉴

前端工具更新很快，但并不是每个版本都值得记住。2022 年这次变化之所以留下来，是因为它改变了后续项目的默认做法。

React 18 正式发布，createRoot 启用新的并发渲染基础，并加入自动批处理、Transitions 与改进的 Suspense SSR。
