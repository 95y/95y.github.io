Welcome to [Hexo](https://hexo.io/)! This is your very first post.

Check the [documentation](https://hexo.io/docs/) for more information. If you encounter a problem, see [troubleshooting](https://hexo.io/docs/troubleshooting.html) or open an issue on [GitHub](https://github.com/hexojs/hexo/issues).

## Quick Start

### Create a new post

```bash
npm run new -- "My New Post"
```

### Run the local server

```bash
npm run dev
```

### Generate static files

```bash
npm run build
```

### Deploy to GitHub Pages

```bash
npm run deploy
```
