这次升级真正解决了什么

Node 版本不再只是后端问题，它直接决定 Vite、webpack、测试工具和包管理器能否运行。

从当时的开发现场说起

Node.js 16 发布并随后进入 LTS。前端工具链开始更广泛依赖原生 ESM、更新的 V8 和稳定 ABI。

版本号之外的变化

  1. package.json 的 type 字段逐渐成为模块边界的重要配置
  2. 工具作者需要同时处理 ESM 与 CommonJS 消费方式
  3. 更现代的运行时允许构建工具减少语法兼容包袱
